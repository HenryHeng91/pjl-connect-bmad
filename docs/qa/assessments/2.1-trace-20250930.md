### Requirement Mappings

#### AC1: A Customer Telegram bot is created and connected to the Laravel backend.

**Coverage: FULL**

- **Integration Test**: `tests/Feature/TelegramWebhookTest.php::test_it_rejects_invalid_webhook_secret`
  - **Given**: An incoming request to the Telegram webhook URL with an invalid secret.
  - **When**: The request is processed.
  - **Then**: The server responds with a 403 Forbidden status, confirming the route is protected.
- **Integration Test**: `tests/Feature/TelegramWebhookTest.php::test_it_processes_valid_webhook_and_creates_booking`
  - **Given**: A valid incoming webhook request with a correct secret.
  - **When**: The request is processed.
  - **Then**: The server responds with a 200 OK status, confirming the connection is successful.

#### AC2: The bot can receive file submissions (PDF, JPG, Excel).

**Coverage: FULL**

- **Integration Test**: `tests/Feature/TelegramWebhookTest.php::test_it_processes_valid_webhook_and_creates_booking`
  - **Given**: A mocked Telegram update containing a document.
  - **When**: The webhook controller processes the update.
  - **Then**: The file is downloaded and stored locally, and its path is saved to the database.
- **Note**: While the test uses a PDF, the underlying logic for downloading and storing the file is agnostic to the specific file type among the accepted ones.

#### AC3: When a file is received, the system creates a new shipment record with a "New" status, attaches the file, and logs the customer's Telegram user ID.

**Coverage: FULL**

- **Integration Test**: `tests/Feature/TelegramWebhookTest.php::test_it_processes_valid_webhook_and_creates_booking`
  - **Given**: A valid webhook with a file submission from a Telegram user.
  - **When**: The webhook is processed.
  - **Then**: 
    - A `Company` record is created with the user's Telegram ID.
    - A `Booking` record is created with the user's Telegram ID.
    - A `Shipment` record is created with a "New" status.
    - The submitted file is stored, and its path is linked to the `Shipment` record.
